# Hero-блок благодійного фонду (p1)

Перший екран у HTML/CSS, без фреймворків і без збірки. Відкрийте `index.html` у браузері.

## Структура

```
p1-hero/
├── index.html                  — готова сторінка (статичний рендер блоку)
├── css/hero.css                — стилі блоку
└── templates/
    ├── hero.njk                — макрос Nunjucks для конструктора сторінок (синтаксис сумісний з Jinja2/Twig)
    └── hero.example.json       — приклад даних для макросу
```

## Адаптив

| Ширина      | Макет  | Що змінюється |
|-------------|--------|----------------|
| ≥ 1024 px   | 1440   | дві колонки (`1fr / 500px`), картка вирівняна по центру по вертикалі |
| 600–1023 px | 768    | одна колонка, картка до 460 px, кнопки в ряд |
| < 600 px    | 375    | кнопки одна під одною, рядок про звіти прихований, картка на всю ширину |

Підхід mobile-first: усі розміри задані через custom properties (`--title-size`, `--btn-h`, `--glow-*` тощо), а медіазапити змінюють тільки змінні. Так видно, що саме відрізняється між брейкпоінтами.

## Повторне використання в конструкторі

- **BEM**: `hero`, `hero__*`, `fund-card`, `fund-card__*`, а `btn` і `badge` — незалежні компоненти, їх можна використовувати поза hero.
- **Ізоляція**: блок має `isolation: isolate` і `overflow: hidden`, тож світлова пляма (`::before`) не виходить за межі секції й не перекриває сусідні блоки.
- **Темізація**: кольори винесені в змінні на `.hero`. Іншу тему можна задати модифікатором, наприклад `.hero--light { --hero-bg: …; }`, не чіпаючи решту CSS.
- **Шаблон**: макрос `hero(data)` рендерить тільки ті частини, які є в даних (без картки, без другої кнопки, без примітки). Замість заглушки можна передати `card.image`, і тоді виводиться `<img>` з `object-fit: cover`.
- **Доступність**: `section[aria-labelledby]`, правильна ієрархія h1 → h2, `:focus-visible` на кнопках, `prefers-reduced-motion`, декоративні елементи позначені `aria-hidden`.

## Як знімалися розміри

Скриншоти макета я поміряла попіксельно (знімки 768 і 375 зроблені з щільністю 2x, тому значення ділила на 2). Потім робила скриншоти своєї верстки в headless Edge на тих самих ширинах і порівнювала поруч: позиції блоків, ширину рядків, переноси слів. Основні значення:

- контейнер 1100 px; десктопний заголовок 59/68 px, планшетний 44 px, мобільний 26 px;
- основний текст: Inter 18/28 (десктоп), 16/24 (планшет), 15.5/23 (телефон);
- кнопки: висота 54 px (52 на телефоні), радіус 12 px; кнопка в картці 44 px;
- картка: padding 18 px, радіус 24 px, фото 16:10 з радіусом 14 px, тінь `0 30px 60px -10px rgba(6,16,32,.55)`;
- світлова пляма: `radial-gradient` #FFC928 з прозорістю 0.55 → 0, радіус 320 px, центр праворуч угорі (на планшеті 260 px, на телефоні ледь помітна).

Опис збору в картці й рядок про звіти на знімках набрані округлим шрифтом, тому для них я взяла Nunito 500, а не Inter. Основний текст набрано Inter 400, як у ТЗ.
